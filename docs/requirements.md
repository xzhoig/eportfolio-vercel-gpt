# Assignment requirements and implementation mapping

Source: the supplied **CIS222 Web Design and Development & CIS282 Web Development and Security — Individual Assignment 30%** brief and **Assignment marking rubric**. The brief requires at least five HTML pages. The rubric is marked out of 100 and gives A–E performance descriptions; it does not specify numeric weights for individual categories.

## Brief requirements

| Requirement | Project evidence |
| --- | --- |
| At least five `.html` files | Seven main pages: `index.html`, `personal.html`, `experience.html`, `education.html`, `skills.html`, `work.html`, `sitemap.html`; six additional demo pages under `demos/` |
| Personal information | `personal.html`; short introduction on `index.html` |
| Working experience | `experience.html` clearly presents academic practice and completed exercises; it does not assert employment |
| Education background | `education.html`, using the verified programme and institution and user-supplied 2025 start year |
| Special skills | `skills.html`, supported by visible evidence in the original HTML and CSS exercises |
| Other related information | `work.html` with six real coursework showcases, demonstrations, original archives, and the About Me download |
| Well-linked webpages | Shared navigation and footer; local project links, downloads, and demo return links; `sitemap.html` lists destinations |
| Site Map | Dedicated `sitemap.html` page |
| Interactive components | Mobile navigation; work search and filters; project detail dialog; CSS playground; back-to-top control; local demo form interactions |
| Responsive components | Fluid layouts, responsive grid changes, mobile navigation, responsive media, touch-friendly controls |
| HTML, CSS, and JavaScript | Plain HTML pages with shared CSS and JavaScript; no framework or build tool required |
| Appropriate images | Local project previews/illustrations and a reserved `images/profile.jpg` portrait path; no borrowed personal photograph |
| One properly organized root folder | All pages, styles, scripts, images, demos, documentation, and downloads inside `nelson-portfolio/` |
| ZIP submission | Complete project archive retaining the `nelson-portfolio/` root folder |

The source brief says real information is not required. The user has imposed a stricter rule: use verified information and do not invent facts. That rule governs this website.

## Rubric mapping

| Rubric category | Highest-band description | Evidence to inspect |
| --- | --- | --- |
| Number of webpages | Five webpages | Seven main HTML pages plus six working demo pages |
| Linkage | All pages and items are well linked | Shared navigation, footer, sitemap, work cards, demo links, document/archive downloads |
| Content | Adequate and appropriate information | Personal, experience, education, and skills pages; substantive descriptions of six submitted exercises; transparent source notes |
| Layout design | Excellence in use of DIV, table, and content position | Consistent container/grid layout, readable content hierarchy, structured project cards, and appropriate tabular information |
| Interactive and responsive components | Excellence; the rubric explicitly lists interactive buttons and mouse-over effects | Navigation, filtering/search, details dialog, CSS controls, local demo forms, hover/focus states, responsive layouts |
| Use of image | Excellence in image size, quality, and position | Responsive project imagery and portrait frame; `images/profile.jpg` supports the owner's own photograph |
| Use of CSS and JavaScript | Precisely format the website and use JavaScript functions for different functions/actions | Shared styling, responsive rules, transitions, reduced-motion rules, several independent interactive features |

## Review before submission

- Open every main page and demo at desktop and phone widths.
- Check navigation, sitemap, project previews, return links, and every download.
- Add the owner's photograph at `images/profile.jpg` before submitting if a portrait is desired.
- Check the website with keyboard navigation, reduced motion, and JavaScript disabled.
- Confirm that demo forms explain their local demonstration behavior.
- Keep the archive's full root folder and all relative asset paths intact.

The deadline printed in the source brief is **13 December 2026, 23:59**. This document maps the supplied criteria to the project; it does not promise an assessment result.
